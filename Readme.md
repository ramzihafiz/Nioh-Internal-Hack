# Overview
	Cheat HP dan Ki untuk game Nioh ini adalah Project pribadi saya untuk belajar tentang CPP.

## Injector
	Injector yang digunakan dalam Developingnya adalah GH Injector dari Guided Hacking

## How To Use
	- Compile solution untuk membuat dll ( hack )
	- Buka GH Injector
	- Di GH Injector select process (attach) ke game "nioh.exe"
	- Setelah itu Add files, pilih file Dll ( hack ) yang di compile tadi. Lalu Inject
	- Setelah itu akan muncul console
	- Hack sudah bisa digunakan
